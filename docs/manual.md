# Manuale

## Credenziali

Le credenziali sono sempre una coppia username password dove la password e' uguale all'username.

## Dati

Come convenzione a fianco ad ogni dato e' presente un numero tra parentesi che rappresenta l'id di quel record nella
sua tabella, ad esempio "Shawshank Library (1)" vuol dire che questa libreria ha record con id `1` nella tabella "library"
